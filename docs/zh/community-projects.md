# 社区项目

> 英文版：[community-projects.md](../community-projects.md)

以下项目由社区构建与维护，感谢所有贡献！这些项目并非 OmniVoice 团队官方支持。

如需添加自己的项目，请提交 PR。

---

- **[ComfyUI-OmniVoice-TTS](https://github.com/Saganaki22/ComfyUI-OmniVoice-TTS)** —
  ComfyUI 自定义节点，用于 OmniVoice 文本转语音。

- **[vLLM-Omni](https://github.com/vllm-project/vllm-omni)** —
  面向全模态模型的高效推理框架，支持 OmniVoice 服务化部署。

- **[pyVideoTrans](https://github.com/jianchang512/pyvideotrans)** —
  带配音与字幕的视频翻译工具，支持 OmniVoice 作为 TTS 引擎。

- **[MLX-Audio](https://github.com/Blaizzy/mlx-audio)** —
  基于 Apple MLX 的 TTS、STT、STS 库，在 Apple Silicon 上高效运行 OmniVoice 等模型。

- **[RealtimeTTS](https://github.com/KoljaB/RealtimeTTS)** —
  实时文本转语音，支持 OmniVoice 作为 TTS 引擎。

- **[TTS-WebUI](https://github.com/rsxdalv/TTS-WebUI)** —
  多模型 TTS 的 Gradio Web UI，OmniVoice 为后端之一。

- **[OmniVoice-Studio](https://github.com/debpalash/OmniVoice-Studio)** —
  OmniVoice 语音生成的桌面应用。

- **[omnivoice-server](https://github.com/maemreyo/omnivoice-server)** —
  OpenAI 兼容 HTTP 服务，通过 `/v1/audio/speech` 提供 OmniVoice；支持持久化克隆的 voice profile、句子级流式与可选 Bearer 认证。

- **[omnivoice-rs](https://github.com/FerrisMind/omnivoice-rs)** —
  GPU 优先的 Rust 工作区：OmniVoice 推理、parity 校验、CLI 与基于 Candle 的 OpenAI 兼容 HTTP 服务。

- **[omnivoice-trtllm](https://github.com/tlitech/omnivoice-trtllm)** —
  使用 TensorRT-LLM 与 Triton Inference Server 在 Modal 上部署 OmniVoice，速度优于 PyTorch。

- **[Auris](https://github.com/nikhilprasanth/Auris)** —
  离线有声书阅读器（EPUB、PDF、TXT），本地 OmniVoice TTS，角色感知音色与按书 narrator 控制。
